# CypherMonkey Labs Reusable Studio Blueprint (`LAB_TEMPLATE.md`)

> **Goal:** Copy this lab into **9 to 10 sibling themed labs** immediately, and scale the shared **Header, Bot, and Downloads** architecture across **100+ unified educational apps** under **CypherMonkey Labs** (`cyphermonkeylabs.com`).

---

## 1. Architecture Overview: What Stays Shared vs. What Changes Per Lab

Every CypherMonkey Labs app is a **zero-build, offline-first, CSP-strict ES module Progressive Web App** with three shared shell pillars and one pluggable content folder:

```
<lab-repo>/
├── index.html                 # Shared Shell: Top bar (#topbar), Bot (#lab-bot), Footer (#site-footer)
├── manifest.webmanifest       # PWA Manifest (customise name, short_name, theme_color)
├── sw.js                      # Offline Service Worker (scoped to "./")
├── assets/
│   ├── cyphermonkey-zodiac.svg # Canon CypherMonkey Zodiac Monkey Emblem + cyphermonkeylabs.com
│   ├── favicon.svg            # Zodiac Monkey App Icon (SVG)
│   ├── icon-192.png           # PWA 192x192 Icon

├── css/

│   ├── bot.css                # Shared Draggable Bot + Aura + Customiser Panel
```

## 2. Shared Component Contracts (Unifying 100+ Apps)

To unify 100+ apps under `cyphermonkeylabs.com`, every lab imports [`js/cm-shared.js`](js/cm-shared.js) and preserves four DOM contracts:

### A. Shared Header (`#topbar` + `js/cm-shared.js`)
- **DOM ID:** `#topbar`
- **Brand Lockup:** Displays the CypherMonkey Zodiac Monkey SVG (`zodiacMonkeySvg(32)`) inside `.brand-mark`, the lab's title in `.brand-name`, and `cyphermonkeylabs.com` in `.brand-sub` (visible on desktop, tablet, and phone).
- **Controls:** Hamburger `#menu-toggle`, instant `/` search (`#top-search`), lesson progress bar (`.top-progress`), quick links, `#pwa-install-btn` (`data-install-app`), `#help-btn` (`data-open-help`), and Display theme switcher (`ink`, `paper`, `terminal`, `contrast`).

### B. Shared Right-Side Bot (`#lab-bot` + `#bot-panel`)
- **DOM IDs:** `#lab-bot` and `#bot-panel`
- **Capabilities:**
  - Sits in the right-side lane by default, scales via `--py-s` (`Small`, `Medium`, `Large`, `Huge`), and supports 6 colours and 6 skins (including `Zodiac Monkey`).
  - **Obstacle-Dodging Engine ([`js/bot.js`](js/bot.js)):** Automatically clamps within the viewport (`--top-h`, `--bar-h`, `--side-now`) and dodges `main h1`, `#site-footer .brand-icons`, `#site-footer .footer-bar`, `main .hero-cta`, `main .pager`, and `main .dl-actions`.
  - **Tap Panel ([`js/botpanel.js`](js/botpanel.js) + [`js/pycustom.js`](js/pycustom.js)):** 9 quick-action tiles (`Level 1`, `Level 2`, `Level 3`, `Foundations`, `Audio`, `Video`, `Downloads`, `Games`, `Hints`), Socratic 4-rung lesson helper, and local customiser.

### C. Shared Download Center (`#/downloads` + [`js/downloadcenter.js`](js/downloadcenter.js))
- **Manifest Driven:** Reads `downloads/modules/manifest.json` (generated by `pipeline/build_downloads.py` from `content/<module>/module.md`) and renders filterable cards for `PDF`, `DOCX`, `PPTX`, `HTML`, and `PNG` with SHA-256 checksums, plus the CypherMonkey zodiac monkey stamp and `cyphermonkeylabs.com` badge.
- **Touch Safety:** On `@media (max-width: 899px)`, `.dc-files` reserves `padding-right: calc(114px * var(--py-s, 1.18) + 22px)` so download links never sit underneath the bot.

### D. Shared Canon Footer (`#site-footer`)
- **DOM ID:** `#site-footer[data-canon-footer]`
- **Required Elements:**
  1. `.disclaimer-panel` (independent, free, learning-only student project; no outcome or income promised).
  2. `.footer-zodiac-lockup` with the CypherMonkey zodiac monkey emblem, `CypherMonkey Labs`, and `cyphermonkeylabs.com`.
  3. `.brand-icons` with the 3 canon links (`https://cyphermonkeylabs.com/`, `https://github.com/CypherMonkeyLabs`, `https://linktr.ee/cypherMonkey`).
  4. `.footer-bar` with the 7 shortcut pills (`Home`, `Slides`, `Diagrams`, `Labs`, `Downloads`, `Sources`, `Help`).

## 3. Step-by-Step Recipe: Cloning This Lab into a New Themed Lab

1. **Branch / Template Copy**
   ```bash
   cp -R python-lab-free-university-mesmerizing <new-lab-slug>
   cd <new-lab-slug>
   ```
2. **Set Lab Identity (5 Minutes)**
   - In `index.html` and `manifest.webmanifest`, update `<title>`, `name`, `short_name`, and `description` (keep `cyphermonkeylabs.com` and the zodiac monkey icon).
   - In `scripts/make_media.py`, update the title string on the splash screen (`"Python Lab"` → your new lab name) and the 4 spoken audio scripts in `AUDIO_LESSONS`, then run:
     ```bash
     python3 scripts/make_media.py
     ```
3. **Swap the In-Browser Runner (`js/runner.js`)**
   - For Python/Data labs: keep `vendor/pyodide/`.
   - For JavaScript/TypeScript labs: execute in a sandboxed Web Worker.
   - For SQL labs: vendor `sql.js` (SQLite compiled to WebAssembly).
   - For C/Rust/Shell labs: use a deterministic AST/trace evaluator or vendored WASM binary (always list every vendored file and SHA-256 in `THIRD_PARTY_MANIFEST.json`).
4. **Author Cited Content (`js/content/` & `content/`)**
   - Replace `js/content/sources.js` with primary documentation links for the new subject.
   - Replace `js/content/*.js` tracks and update `data/lesson-map.json`.
   - Update `content/level-00..10/module.md` and run `pipeline/build_downloads.py` + `node scripts/make_downloads.mjs` + `node scripts/build_release_downloads.mjs`.
5. **Run the 5 Automated Gate Checks**
   ```bash
   python3 scripts/csp_check.py
   python3 scripts/licence_manifest.py
   node scripts/validate_lessons.mjs
   node scripts/build_release_downloads.mjs --check
   npx playwright test
   ```

## 5. Scaling to 100+ Apps: Shared Package Pattern

When maintaining 100+ CypherMonkey Labs apps:
1. Keep [`js/cm-shared.js`](js/cm-shared.js), [`js/bot.js`](js/bot.js), [`js/botpanel.js`](js/botpanel.js), [`js/pycustom.js`](js/pycustom.js), [`js/downloadcenter.js`](js/downloadcenter.js), [`js/pwa.js`](js/pwa.js), and `css/{shell,bot,footer,studio,howto}.css` identical across repositories (verified by a single SHA-256 manifest check in CI).
2. Store all per-lab customisation (lab title, bot default name/colour, accent palette, and section list) in `js/content/` and `data/lesson-map.json`.
3. Every lab automatically inherits the CypherMonkey zodiac monkey symbol, `cyphermonkeylabs.com` branding, PWA offline installer, obstacle-dodging bot, and canon disclaimer.
