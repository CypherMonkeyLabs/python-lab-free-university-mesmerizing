## Library search (2026-10-17)
Before writing the PR1 and PR2 tooling, the team library (`libsearch.py`, licence-safe filter) was searched for: licence notices, PR/contributing templates, CSP checks, link checkers, front-matter schemas, Python curricula. No entry was a usable drop-in, so **no third-party code or text was copied**. One entry was read for ideas only: thedaviddias/Front-End-Checklist (MIT), https://github.com/thedaviddias/Front-End-Checklist, for the habit of a per-PR checklist. Credit given here regardless.
