# Learning-science sources

Each reference below was looked up on Crossref on 2026-10-17 (title, journal, year and DOI match). Only the bibliographic record was checked; the papers were **not** read in full for this PR, so the "used for" column is the lab's design intent, not a claim about every finding in the paper.

|---|---|---|
| Retrieval practice (quizzes, flashcards) | Roediger, H. L., & Karpicke, J. D. (2006). Test-Enhanced Learning. *Psychological Science*. | 10.1111/j.1467-9280.2006.01693.x |
| Spaced review scheduling | Cepeda, N. J., et al. (2006). Distributed practice in verbal recall tasks: A review and quantitative synthesis. *Psychological Bulletin*, 132(3). | 10.1037/0033-2909.132.3.354 |
| Which study techniques to prefer | Dunlosky, J., et al. (2013). Improving Students' Learning With Effective Learning Techniques. *Psychological Science in the Public Interest*. | 10.1177/1529100612453266 |

## Not verified (do not cite yet)
- Parsons problems (line-ordering exercises): the original Parsons & Haden (2006) paper was not located in the lookup (the search returned an unrelated record). Cite only after a human finds the real record.
- Any claim that these techniques give a specific percentage gain. The lab makes no such claim.

Rule for lesson pages: say "research suggests" only next to a reference from this list; otherwise state the practice without claiming evidence.
